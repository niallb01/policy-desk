# When to escalate

## Engineering

Escalate to engineering only when one of these is true:

- More than one customer is affected by an outage.
- Data loss is suspected.
- The bug is reproduced on the current version after the matching runbook steps have been done.

## Stay on the front line

Do not escalate how-to questions, a single user who cannot sign in, or a billing question. Those stay with support. Billing exceptions go to a billing lead, not to engineering.

## What the ticket needs

An escalation includes the customer id, the time the problem started, and what was already checked. Engineering sends back a note the agent can quote. The agent does not invent a cause while waiting.
